# RushPilot 下载与更新

这里是 **RushPilot**（发布版）的下载与在线更新仓库，只存放打包好的应用，不包含源码。

## 下载

到右侧的 [Releases](https://github.com/leftwalker-sudo/RushPilot-Public-Releases/releases) 页面，下载最新版本的 `RushPilot-版本号-Release.zip`，解压后把 `RushPilot.app` 拖进“应用程序”文件夹。压缩包里附有《RushPilot 使用说明》。

## 第一次打开

这个应用没有苹果开发者签名，第一次打开会被系统拦下。放行方法：在提示框点“完成”，然后打开“系统设置 › 隐私与安全性”，在最下面的“安全性”里点“仍要打开”，输入电脑密码确认。之后就能正常打开。

## 在线更新

应用打开约 5 秒后会自动检查这里有没有新版本，也可以在“设置 › 关于”里手动检查。检查更新只读取本仓库公开的版本信息，不上传任何内容。
